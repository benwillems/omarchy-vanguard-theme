# Vanguard

![Vanguard](preview.png)

Dark navy and old-glory crimson for Omarchy. The wallpapers are the California coast, a coastal rocket, the Grand Canyon, a storm flag, one car in front of the flag, engine ignition, and two brushed-steel plates.

## Install

```sh
omarchy theme install https://github.com/benwillems/omarchy-vanguard-theme.git
```

That installs it as `vanguard`. You can also copy this folder to `~/.config/omarchy/themes/vanguard` and run:

```sh
omarchy theme set vanguard
```

Cycle backgrounds with `omarchy theme bg next` or the wallpaper picker.

## Remove

```sh
omarchy theme set "Tokyo Night"
rm -rf ~/.config/omarchy/themes/vanguard
```
